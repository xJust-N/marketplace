# Маркетплейс

Проект представляет собой маркетплейс, в котором можно создавать магазины, продукты, оформлять заказы и тд

## Основной функционал

### Аутентификация и авторизация
- Регистрация и вход пользователей
- Управление сессиями
- Защита паролей с хешированием и солью

### Управление магазинами
- Создание и редактирование магазинов
- Просмотр каталога магазинов
- Управление информацией о магазине

### Управление товарами
- Добавление, редактирование и удаление товаров
- Каталог товаров с пагинацией

### Система заказов
- Добавление товаров в корзину
- Оформление заказов
- Отслеживание статусов заказов
- История заказов

### Система ролей пользователей
- **Покупатель** - просмотр товаров, оформление заказов
- **Продавец** - управление магазином и товарами
- **Покупатель-Продавец** - комбинированные возможности
- **Модератор** - модерация контента
- **Администратор** - полный доступ к системе

### Работа с медиа-контентом (поддержка различных MIME-типов)
- Загрузка аватара профиля
- Прикрепление нескольких фотографий к товарам

## Использованные технологии:
- **Java** - основной язык программирования
- **Servlets API** - для обработки http запросов
- **JDBC** - работа с базой данных
- **PostgreSQL** - реляционная база данных
- **Apache Tomcat** - контейнер сервлетов
	
### Frontend
- **JSP** - шаблонизатор
- **HTML/CSS** - верстка и стили
- **JavaScript** - клиентская логика

### Инфраструктура
- **Maven** - управление зависимостями и сборка
- **SLF4J + Logback** - логирование сервисов
